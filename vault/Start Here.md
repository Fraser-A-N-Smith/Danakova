# Campaign Vault

Welcome. This is our shared notes vault — everyone can edit everything, live,
at the same time. Two people typing in the same note will not clobber each
other; you will see their cursor.

## The folders

| Folder | What goes in it |
| --- | --- |
| `Sessions/` | One note per session. Recaps, what happened, what we decided. |
| `Characters/` | Player characters. Yours is yours — write as much as you like. |
| `NPCs/` | People we've met. Add them as we meet them. |
| `Locations/` | Towns, dungeons, regions. |
| `Quests/` | Open threads, leads, and things we said we'd come back to. |
| `Lore/` | World history, factions, religions, rumours. |
| `Items/` | Notable loot and magic items. |

## Linking notes

Type `[[` and start typing a name to link to another note — `[[Sessions/Session 01]]`.
If the note doesn't exist yet, the link still works and will create it when clicked.
Any note you're reading shows its **backlinks** — everything that points at it —
which is the fastest way to find "where did we meet this person again?"

## House rules for the vault

- **Everything here is visible to all six of us.** There are no private folders.
  If it's a secret, it does not go in this vault.
- Put your name on things you write in session notes so we know who remembers what.
- Don't rename or delete other people's notes. Adding is free; destroying is not.
